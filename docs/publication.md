# Synthetic publication

The paper and its selected reproducibility source archive are deposited together
at [Zenodo record 23321281](https://zenodo.org/records/23321281), version DOI
[10.5281/zenodo.23321281](https://doi.org/10.5281/zenodo.23321281).
The concept DOI, which groups future versions, is
[10.5281/zenodo.23321280](https://doi.org/10.5281/zenodo.23321280).

Synthetic is a standalone educational paper and numerical package. It selects
formal results from FEP_Formal and gives worked examples with explicit assumptions
and transfer boundaries. See [positioning](positioning.md), [methods](methods.md)
and the [resource guide](resources.md).

The publication references the published
[FEP_Formal paper](https://zenodo.org/records/23220027) and
[GNN paper](https://zenodo.org/records/7803328), with separate software archive
identifiers for [FEP_Formal](https://zenodo.org/records/23196891) and
[GNN](https://zenodo.org/records/7803313). A cited paper, a software archive and an
imported Lean revision serve different purposes; the immutable Lean dependency
in `formal/lakefile.lean` controls actual proof imports.

The source ZIP records 146 selected files and their SHA-256 hashes, including
numerical code, tests, manuscript sources, formal sources, lockfiles, generated
figures and experiment data. It is a snapshot of the scientific working tree,
not a GitHub release or a complete clone of the publication template. Rendering
uses the separate docxology/template methods described in
[the rendering guide](rendering_pipeline.md).

The [publication lecture](lecture.md) opens with a screenshot of the same PDF
cover. Its linked slides and frozen source bundle accompany the twenty-minute
Daniel narration. Paper, source, media and delivery receipts verify distinct
artifacts; they do not substitute for one another.
