# Synthetic lecture contract

`release_manifest.json` describes the immutable `synthetic-teaching-v0.6.0`
lecture edition. Keep it intact when repackaging identical assets into a later
public distribution; the root `publication.json` owns that distribution identity.

`slides.pdf`, captions, transcript, notes, and poster accompany the root MP4.
Change them only as part of an explicitly regenerated and verified media edition.
Read [lecture/AGENTS.md](lecture/AGENTS.md) before modifying production sources.
Use [the lecture guide](../../docs/lecture.md) for frozen replay inputs and commands.
