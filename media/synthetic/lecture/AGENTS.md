# Frozen authoring contract

This directory is the historical `edition_v15` input set, not a live reflection
of current repository prose. Its original publication links and source inventory
remain part of that edition. Read [README.md](README.md) for script roles and
[the lecture guide](../../../docs/lecture.md) for replay prerequisites.

For a new media edition, use a fresh output directory, freeze scientific and
authored inputs, verify source hashes, and retain failed receipts. Reuse measured
recordings only when the narration agrees exactly. Changes to words, visual
clocks, captions or animations require their matching checks and a new manifest.
Replay with frozen audio makes no paid synthesis calls; voice preparation is a
separate action. Keep the script/runtime/input identities in each delivery receipt.
